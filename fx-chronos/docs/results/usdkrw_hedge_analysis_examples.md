# USD/KRW 환위험 계산 엔진 지급·수취 예시

## 1. 목적

환율 예측 결과를 기업 계약의 원화 지급액 또는 수취액으로 변환하는 계산 엔진을 검증했다. 예측 모델과 계산 엔진은 분리했으며, 계산 함수 안에서 Chronos-2를 직접 호출하지 않는다.

이 문서의 계약은 기능 확인을 위한 가상 예시다. 실제 기업 계약, 금융상품 추천 또는 최적 헤지 비율 제안이 아니다.

## 2. 입력 예시

지급과 수취의 위험 방향을 비교하기 위해 `side`를 제외한 조건을 동일하게 유지했다.

```text
통화쌍: USD/KRW
외화 금액: USD 1,000,000
결제일: 2026-07-30
현재 기준환율: 1,548.4 KRW per USD
헤지 비율: 50%
헤지 금액: USD 500,000
미헤지 금액: USD 500,000
헤지 환율: 1,548.4 KRW per USD
계약 방향: 지급 또는 수취
example_only: true
```

## 3. 예측과 시나리오 출처

점 예측과 위험 시나리오의 출처를 분리해 기록한다.

```text
point
→ Random Walk + Chronos-2 축소 앙상블 α=0.5

lower / median / upper
→ Chronos-2 Zero-shot q0.1 / q0.5 / q0.9
```

Chronos-2 분위수는 과거 백테스트에서 목표 포함률에 미달했다. 따라서 확정적인 80% 신뢰구간이 아니라 참고용 위험 시나리오로만 사용한다.

## 4. 계산 정의

```text
헤지 원화 금액
= 헤지 외화 금액 × 헤지 환율

미헤지 원화 금액
= 미헤지 외화 금액 × 시나리오 환율

총 원화 지급·수취액
= 헤지 원화 금액 + 미헤지 원화 금액

완전 무헤지 원화 금액
= 전체 외화 금액 × 시나리오 환율

기준 원화 금액
= 전체 외화 금액 × 현재 기준환율
```

`favorable_pnl_vs_reference_krw`는 계약 방향에 관계없이 양수면 기업에 유리하고 음수면 불리하도록 정의한다.

```text
지급 계약
favorable P/L = 기준 원화 금액 - 총 원화 지급액

수취 계약
favorable P/L = 총 원화 수취액 - 기준 원화 금액
```

`hedge_effect_vs_unhedged_krw`도 양수면 같은 시나리오의 완전 무헤지보다 헤지가 유리하다는 의미다.

```text
지급 계약
hedge effect = 완전 무헤지 지급액 - 헤지 후 지급액

수취 계약
hedge effect = 헤지 후 수취액 - 완전 무헤지 수취액
```

## 5. 지급 계약 결과

지급 계약은 환율 상승 시 필요한 원화 금액이 증가하므로 불리하다.

| 시나리오 | 환율 | 총 원화 지급액 | 기준 대비 유리한 손익 |
|---|---:|---:|---:|
| 앙상블 점 예측 | 1,549.9249 | 1,549,162,427원 | -762,427원 |
| Chronos 하한 | 1,508.3633 | 1,528,381,641원 | +20,018,359원 |
| Chronos 중앙 | 1,551.4497 | 1,549,924,854원 | -1,524,854원 |
| Chronos 상한 | 1,595.5544 | 1,571,977,222원 | -23,577,222원 |

상단 환율 시나리오에서는 원화 지급 부담이 증가하고 하단 시나리오에서는 감소한다.

## 6. 수취 계약 결과

수취 계약은 환율 하락 시 받는 원화 금액이 감소하므로 불리하다.

| 시나리오 | 환율 | 총 원화 수취액 | 기준 대비 유리한 손익 |
|---|---:|---:|---:|
| 앙상블 점 예측 | 1,549.9249 | 1,549,162,427원 | +762,427원 |
| Chronos 하한 | 1,508.3633 | 1,528,381,641원 | -20,018,359원 |
| Chronos 중앙 | 1,551.4497 | 1,549,924,854원 | +1,524,854원 |
| Chronos 상한 | 1,595.5544 | 1,571,977,222원 | +23,577,222원 |

같은 환율 시나리오에서 총 원화 금액은 지급과 수취가 같지만, 기업에 유리한 손익과 헤지 효과의 부호는 정확히 반대다.

## 8. 현재 완료 범위

- 공통 `ForecastScenario` 구조
- Random Walk, Chronos-2, 축소 앙상블 시나리오 구분
- 한 기준일의 예측 CSV 변환
- 지급·수취 계약 계산
- 헤지 금액 또는 비율 입력
- 시나리오별 원화 금액
- 현재 기준환율 대비 유리·불리 손익
- 완전 무헤지 대비 헤지 효과
- JSON과 CSV 내보내기
- 데이터·모델 한계 경고

## 9. 아직 포함하지 않은 범위

- 은행 스프레드
- 환전 및 송금 수수료
- 세금
- 선물환, 옵션 등 실제 금융상품 조건
- 계약별 현금흐름 할인
- 거래 상대방 신용위험
- 최적 헤지 비율 계산
- 특정 상품 자동 추천
- 결제일이 비관측일일 때의 사용자 승인 기반 날짜 정책
- JPY/KRW, EUR/KRW, CNY/KRW 계약

결제일이 예측 날짜에 없으면 가까운 날짜로 자동 이동하거나 환율을 보간하지 않고 오류로 처리한다.
