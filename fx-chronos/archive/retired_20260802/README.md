# Retired experiments archive

이 디렉터리는 2026-08-02에 현재 USD/KRW 서비스 범위에서 사용하지 않는 연구 코드와 산출물을 삭제하지 않고 이동한 아카이브다.

## 현재 활성 범위

```text
통화: USD/KRW
예측 기간: 20·60·90개 실제 환율 관측
모델: Random Walk + Chronos-2 Zero-shot 고정 alpha=0.5 축소 앙상블
데이터: 한국은행 ECOS USD/KRW 일별 매매기준율
환헤지: 다른 담당자 인수를 위해 활성 코드 유지
```

## 아카이브 범위

- 탈락한 JPY/KRW, Broad Dollar, 한미 3년물 금리차 공변량 실험
- 탈락한 USD/KRW 로그수익률 타깃 실험
- 최종 Test에서 일반화되지 않은 LoRA 파인튜닝 코드·체크포인트·산출물
- 2026년 규칙을 통과하지 못한 고정 예측구간 보정 코드·산출물
- 구형 반기별 H5·H20·H30·H60 비교 산출물
- 위 실험에만 필요한 FRED·JPY·금리 데이터, 설정, 테스트와 결과 문서

파일은 원래 최상위 분류인 `src`, `tests`, `configs`, `data`, `outputs`, `docs`를 최대한 유지해 배치했다. 아카이브 코드는 활성 패키지의 일부가 아니므로 이 위치에서 전체 테스트나 모듈 실행을 보장하지 않는다.

복구가 필요하면 관련 코드 하나만 꺼내지 말고 동일 실험의 설정·데이터·테스트·산출물과 문서를 함께 검토한다. 과거 문서 안의 경로는 이동 당시 원래 경로를 가리키는 연구 기록일 수 있다.
