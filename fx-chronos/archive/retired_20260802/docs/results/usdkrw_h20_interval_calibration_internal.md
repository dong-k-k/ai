# USD/KRW 20영업일 예측구간 내부 보정 결과

## 1. 과소포착 문제

Chronos-2의 q0.1~q0.9 구간은 명목상 80% 범위를 의도하지만 context 756의 2018~2021 Validation 실제 포함률은 73.65%였다.

```text
목표 포함률: 80.00%
실제 포함률: 73.65%
하한 아래 이탈: 11.04%
상한 위 이탈: 15.31%
평균 구간 폭: 34.99원
```

이처럼 실제값이 목표보다 자주 구간 밖으로 벗어나는 현상을 과소포착이라고 한다. 위험 분석에서 구간을 실제보다 안정적으로 보이게 만들 수 있으므로 보정 가능성을 검토했다.

## 2. 사전 고정한 보정 방법

결과를 보기 전에 다음 조건을 `fx-chronos/configs/interval_calibration.json`에 고정했다.

```text
보정 구간: 요청 기준일 2018-01-01~2019-12-31
내부 평가 구간: 요청 기준일 2020-01-01~2021-12-31
보정 기준일: 24개, 480행
내부 평가 기준일: 24개, 480행
목표 포함률: 80%
방법: 전역 대칭 additive conformal widening
```

각 보정 행의 비적합 점수는 다음과 같다.

```text
score = max(기존 하한 - 실제값, 실제값 - 기존 상한, 0)
```

480개 보정 점수의 유한표본 80% 순위를 사용해 보정값을 한 번 계산했다.

```text
rank = ceil((480 + 1) × 0.8) = 385
보정값 = 3.008544921875원

보정 하한 = 기존 q0.1 - 3.0085원
보정 중앙 = 기존 q0.5 유지
보정 상한 = 기존 q0.9 + 3.0085원
```

점 예측과 중앙값은 변경하지 않았다.

## 3. 내부 평가 결과

| 항목 | 보정 전 | 보정 후 | 변화 |
|---|---:|---:|---:|
| 포함률 | 74.7917% | 82.7083% | +7.9167%p |
| 평균 구간 폭 | 36.7110원 | 42.7281원 | +6.0171원 |

평균 구간 폭은 16.39% 증가했다. 포함률이 높아진 대가로 위험 범위가 넓어진 것이므로 포함률만 보고 개선됐다고 판단하지 않는다.

보정 후 이탈 방향:

```text
하한 아래: 10.2083%
상한 위: 7.0833%
```

사전 내부 평가 기준인 80%를 전체 평균에서는 통과했다.

## 4. 연도별 결과

| 연도 | 보정 전 포함률 | 보정 후 포함률 | 보정 후 평균 폭 |
|---:|---:|---:|---:|
| 2020 | 69.5833% | 76.2500% | 44.8337원 |
| 2021 | 80.0000% | 89.1667% | 40.6224원 |

2020년은 보정 후에도 80%에 미달했고 2021년은 89.17%까지 올라갔다. 따라서 이 전역 보정이 모든 시장 국면에서 동일하게 잘 맞는다고 주장하지 않는다.

## 5. 예측 구간별 결과

| 구간 | 보정 전 포함률 | 보정 후 포함률 | 폭 증가율 |
|---|---:|---:|---:|
| D+1~D+5 | 74.1667% | 83.3333% | 29.18% |
| D+6~D+10 | 69.1667% | 81.6667% | 18.03% |
| D+11~D+20 | 77.9167% | 82.9167% | 12.96% |

세 구간 모두 내부 평가에서 80%를 넘었지만, 원래 폭이 좁은 단기 구간의 상대적 폭 증가가 가장 컸다.

## 6. 현재 판정

```text
passed_pre_registered_internal_rule: true
status: internal_rule_passed
point_forecast_changed: false
2022~2025 final test used: false
2026 observations used: false
```

이 결과는 Validation 내부에서 시간순으로 나눈 보정·평가 결과다. context 756 자체는 전체 2018~2021 Validation 결과를 보고 선택했으므로 2020~2021을 완전히 미관측 Test라고 부르지 않는다.

현재 판정:

- 전역 대칭 보정이 내부 평가 평균 포함률을 80% 이상으로 높일 가능성을 확인했다.
- 구간 폭이 약 16.39% 증가하는 비용이 있다.
- 연도별 편차가 남아 있다.
- 아직 환위험 출력의 기본 구간으로 교체하지 않는다.
- 다음 신규 평가는 보정값 3.0085원을 고정한 상태에서 수행해야 한다.
- 신규 결과가 나쁘더라도 그 결과를 보고 보정 방법이나 값을 다시 선택하지 않는다.
